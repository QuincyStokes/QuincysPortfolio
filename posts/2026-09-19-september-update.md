# September Update

The past few months have been pretty wonderful. I'm still up in Northern California figuring out what I want to do, and I've been putting more time into teaching + working at a school up here. 

GEODE progress has been a little bit slow, I think the main reason for that is a combination of things.
A lot of what needs to be done is art related, which I'm not incredibly excited to do, likely due to my lack of confidence in my ability. But, it's fun once I get going.
A little bit too I think is related to lack of motivation. Honestly I was ready to be done with GEODE when I released it, but since it surpassed my expectations, I feel like I need to add more. **It's not done.** 

Right now there are still a few things I need to finish before releasing a more public playtest. Those namely include:
- Finishing up the new towers (2.5/4 complete)
- Adding in the Tundra boss (not started)
- Recording SFX for the abovementioned (not started)
- Adding in some more fun items and lore related things (a bit more hard to define)

I really hope to be able to get these done within the next few weeks or month, I'm feeling good about working on it right now. 

# Other Projects

On top of GEODE, I'm really looking forward to starting some other projects. There are some 3d ideas I'd like to try out, as well as dipping my toes into Unreal Engine a bit more. 
It'll be hard to balance all of these things alongside a growing social life, but I don't have any complaints in order about those. 

Life is good right now :)
